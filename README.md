# Bhaskar Bera - Portfolio

A modern, responsive, and dynamic personal portfolio website built to showcase my projects, skills, and experience.

## ✨ Features

- **Modern Tech Stack:** Built with React 19 and Vite for lightning-fast performance.
- **Sleek UI/UX:** Styled using **Tailwind CSS v4** and beautiful components from **shadcn/ui**.
- **Dynamic Animations:** Smooth scroll and entrance animations powered by **Framer Motion**.
- **SEO Optimized:** Dynamic meta tags and page titles managed by **react-helmet-async**.
- **Responsive Design:** Fully responsive layout that looks great on mobile, tablet, and desktop devices.
- **Glassmorphism Aesthetics:** Beautiful frosted glass UI elements for a premium feel.

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Pointer2005/Portfolio2.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Portfolio2
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Start the Vite development server with hot-module replacement (HMR):

```bash
npm run dev
```

Your application will be running at `http://localhost:5173`.

### Build for Production

To create an optimized production build:

```bash
npm run build
```

## 📂 Project Structure

- `src/components/` - Reusable UI components (including shadcn/ui components).
- `src/pages/` - Main page views (Home, About, Skills, Projects, Contact).
- `src/config/` - Site configuration and navigation data.
- `src/data/` - Content data like projects list and skills list.
- `src/router/` - React Router configuration.
